## Running Locally

No build step required. Two options:

**Option 1 — Open directly (simplest):**
```bash
open index.html
```

**Option 2 — Local server (recommended, avoids any browser file:// quirks):**
```bash
# Python 3
python3 -m http.server 8080
```
Then open [http://localhost:8080](http://localhost:8080) in your browser. Press `Ctrl+C` to stop.
